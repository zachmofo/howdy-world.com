Lesson 1 — The Bones of a Ranch Record

HTML · done when four longhorns show in the browser

Today we build the bones. HTML is structure — pens, chute, paper record book. Nothing pretty yet.

Create a folder named ranch-record. Inside it, a file named exactly index.html.

Live result

This is where you'll be at the end of the lesson. Plain on purpose.

Step 1 — the skeleton

Type this first. Every HTML page starts here.
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Howdy World Ranch — Record Card</title>
</head>
<body>

</body>
</html>

<head> is about the page. <body> is what you see.

Step 2 — header and intro

Inside <body>:

<header>
  <h1>Howdy World Ranch</h1>
  <p class="tagline">Livestock Record Card — Fort Worth Stockyards Inspired Herd</p>
</header>

<main>
  <section class="intro">
    <p>
      These animals are inspired by the famous Fort Worth Herd longhorns
      that walk Exchange Street twice a day. We're using them as our
      teaching example while we learn to build tools for the ranch.
    </p>
  </section>

Step 3 — the herd table

  <section class="herd">
    <h2>Current Herd</h2>
    <table>
      <thead>
        <tr>
          <th>Name</th>
          <th>Tag</th>
          <th>Breed</th>
          <th>Notes</th>
        </tr>
      </thead>
      <tbody>
        <tr><td>Black Gold</td><td>FW-01</td><td>Texas Longhorn</td><td>Rare black pattern, 100"+ horns</td></tr>
        <tr><td>Brutus</td><td>FW-02</td><td>Texas Longhorn</td><td>Largest steer in the example herd</td></tr>
        <tr><td>McCree</td><td>FW-03</td><td>Texas Longhorn</td><td>Strong presence</td></tr>
        <tr><td>Blacksmith</td><td>FW-04</td><td>Texas Longhorn</td><td>Newer addition to the drive</td></tr>
      </tbody>
    </table>
  </section>
</main>

<footer>
  <p>Howdy World Coding · Lesson 1 — HTML</p>
</footer>

Rows are <tr>. Header cells are <th>. Data cells are <td>.

Save and open

Save the file. Double-click it or drag it onto a browser. You should see the ranch name and four animals. If it looks boring, you did it right.
